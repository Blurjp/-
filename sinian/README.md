# 思念 · 本地运行的逝者对话 App

用亲人留下的聊天记录、声音和照片，在**手机本地**生成一个可以对话的 AI 模拟。
必须先取得家人一致同意；任何一位撤回，所有资料和模型立即删除。

- 📄 市场与法规调研：[docs/RESEARCH.md](docs/RESEARCH.md)
- 🏗 技术架构、推荐模型、路线图：[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

## 它会做什么

| | |
| --- | --- |
| **家人同意** | 逝者本人生前意愿优先（本人拒绝则永远无法开启）；否则按《民法典》第 994 条，配偶、子女、父母**全部**签字同意；都不在世时由兄弟姐妹、祖父母、孙子女全部同意。每人可分别勾选允许文字/声音/照片/视频，最终取交集。需上传死亡证明（只保留指纹）并声明亲属名单完整。 |
| **导入资料** | 微信（PC 备份工具导出的 txt）、WhatsApp 导出；自动学习口头禅、语气词、表情、消息长度和真实问答例句。家人可补充具体的回忆。 |
| **对话** | 本地大模型（llama.rn）+ 回忆检索；可用 10–30 秒录音零样本克隆声音朗读回复。 |
| **安全** | 常驻"AI 模拟"标识；被问"是你吗"时必须诚实；检测到轻生/"想去陪你"立即跳出角色给热线；不谈钱款、遗产、密码，不给医疗建议；每日时长上限，连续多天使用提醒联系亲友或哀伤辅导；随时"告别与删除"。 |

## 快速开始

```sh
cd core && npm install && npm test     # 27 个核心逻辑测试
cd ../app && npm install
npx expo prebuild && npx expo run:android   # 原生模块，需要开发构建，不能用 Expo Go
```

首次打开后在"设置"中下载模型（见 [推荐模型](docs/ARCHITECTURE.md#推荐模型)），之后完全离线。

## 当前状态

第一阶段原型：核心逻辑有单元测试；App 通过 TypeScript 类型检查，**尚未在真机上跑过**。
声音克隆依赖 llama.rn 的实验性 TTS API，接口可能随版本变化。会动的视频头像在第三阶段。
